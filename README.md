# 🚀 DevStack

### Build Your Ideal Development Stack

DevStack is a simple and interactive web application that helps developers explore different development technologies and build their own ideal technology stack.

Users can browse available technologies, add technologies to their personal stack, remove individual technologies, or clear the entire stack.

---

## ✨ Features

* 🔍 **Explore Technologies** — Browse different frontend, backend, database, and development tools.
* ➕ **Build Your Stack** — Add technologies to create your own development stack and prevent duplicate selections.
* 🗑️ **Manage Your Stack** — Remove individual technologies or remove all selected technologies at once.

---

## 🛠️ Technologies Used

* **React**
* **TypeScript**
